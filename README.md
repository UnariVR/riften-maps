# riften-maps

Map tiles for the Riften Hold menu (Properties tab).

`rift/` is a tile pyramid of The Rift: `rift/<zoom>/<x>_<y>.jpg`, 256 px tiles, zoom 0 (whole Rift) to 7 (full detail); `rift/meta.json` describes its size.

Map imagery from the [UESP Skyrim map](https://gamemap.uesp.net/sr/) (tiles at UESP zoom 8, cropped to The Rift). The Elder Scrolls V: Skyrim © Bethesda Softworks. Used for a non-commercial roleplay community tool.
